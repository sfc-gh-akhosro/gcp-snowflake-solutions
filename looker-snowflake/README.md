# Looker Quickstart with Snowflake

This project is a step-by-step guide to creating a Looker demo and quickstart using Snowflake data.

## Goal

The ultimate goal is to:
1. Create a quickstart for other Solution Engineers in Snowflake to start with working Looker.
2. Write a demo that showcases the capabilities of Snowflake and its integration with Looker.
3. Meet requirements for new integrations specified in `./requirements/Snowflake-Looker Product and GTM plays.md`, including seamless authentication and semantic layer collaborations.
